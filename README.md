# AulaMetrics

**Psychosocial screening for schools, built as an Odoo module: validated questionnaires, automatic scoring, risk alerts and an interactive dashboard.**

School counsellors need to know how their students are doing (well-being, stress, bullying) before problems escalate, but paper questionnaires are slow to score and hard to follow up. AulaMetrics lets a school schedule evaluations for its groups, send each student a private link, score the answers automatically and turn them into alerts and a dashboard that staff can act on.

## What it does

- **Validated instruments** loaded as surveys: WHO-5 (well-being), ASQ-14 (adolescent stress) and a bullying scale with victimisation and aggression subscales.
- **Scheduled evaluations** assigned to academic groups; a cron job opens and closes them automatically.
- **Token-based student portal**: each participation gets a unique link, so students answer without an account.
- **Scoring engine** (Strategy pattern): each instrument has its own scoring class; scores are normalised to 0-100 and computed per subscale, only when every item has been answered.
- **Configurable thresholds and alerts**: individual alerts when a score crosses a threshold (by severity), and group alerts when a set percentage of a class is at risk. Alerts are resolved through a wizard that records the action taken.
- **Executive dashboard** generated with pandas + Plotly: distributions, risk rates and group comparisons for an evaluation.
- **Role-based access**: tutors see aggregated data for their own groups; counsellors and management have wider access, enforced with Odoo record rules.

## Architecture

```
models/
  survey_config.py              single source of truth: instruments, subscales, thresholds, colours
  survey_scoring_strategies.py  one scoring class per instrument
  evaluation.py, participation.py, academic_group.py
  threshold.py, alert.py, alerts_dashboard.py
  dashboard_charts.py           pandas + Plotly dashboard
  report.py                     aggregated results per evaluation
controllers/
  survey_portal.py              public, token-based survey portal
  dashboard_controller.py       serves the interactive dashboard
security/                       groups, access rights and record rules
wizards/                        alert resolution
scripts/generate_demo_data.py   synthetic schools, groups and students
```

Adding a new questionnaire means adding its entry to `survey_config.py`, a scoring class and the survey XML; thresholds, alerts and charts pick it up from the shared configuration.

## Installation

1. Copy the folder into your Odoo `addons` path.
2. Install the Python dependencies: `pip install pandas plotly`.
3. Update the apps list and install **AulaMetrics** (it depends on `base`, `mail` and `survey`).

All demo data is synthetic and generated by `scripts/generate_demo_data.py`. No real student data is included.
