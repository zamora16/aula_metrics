# AulaMetrics

**Psychosocial assessment and educational data analytics for schools, built as an Odoo module: validated questionnaires, automatic scoring, risk alerts, case follow-up and role-based dashboards.**

School counsellors are expected to run standardised psychosocial assessments (well-being, emotional and behavioural difficulties, social relationships), but usually have no system to schedule them, collect answers at scale, score them and spot students at risk, so the work ends up in spreadsheets. AulaMetrics covers that whole cycle, from sending the questionnaire to following up each case. It was refined through demo and feedback sessions with practising school counsellors.

## What it does

- **Validated instruments** loaded as surveys (SDQ, SWLS and a social-relationships questionnaire), with scoring by scale and norm ranges (*baremos*) per questionnaire.
- **Academic years, groups and students**: wizards to open a new year, carry groups over and import students in bulk.
- **Evaluations** assigned to groups and answered through a **token-based portal**, so students need no account.
- **Risk alerts**: automatic alerts when a score crosses a configurable threshold, keyword alerts on open-ended answers (text normalisation, plurals and accents handled), and manual alerts.
- **Case management**: alerts become cases with stages, an owner and an internal message thread.
- **Dashboards**: home hub, evaluation dashboard, score evolution over time, distribution/segmentation of the student body, qualitative dashboard with word clouds, and individual student profiles.
- **PDF reports** per evaluation and per student.
- **Privacy by role**: administrator, counsellor, tutor and school leadership see different levels of detail; tutors and leadership get aggregated, anonymised data. Enforced with Odoo groups and record rules.
- **i18n**: Spanish and Catalan.

## Architecture

```
models/
  core/        academic years and groups, students, evaluations, participations, thresholds, metrics
  survey/      survey extension, scoring strategies (one per instrument), norm ranges, results
  metrics/     alerts, alert keywords, cases, case stages, message threads, qualitative responses
  dashboard/   data queries (pandas) and page builders for every dashboard and report
controllers/   survey portal and dashboard routes (evaluation, segmentation, qualitative)
utils/         role service, constants, chart defaults, palette, styles, language service
wizards/       academic year set-up, student import, manual and resolve-alert wizards
security/      groups, access rights and record rules
static/        SCSS theme, dashboard JS, D3 word cloud
i18n/          Catalan translation
```

Scoring follows a Strategy pattern: each questionnaire has its own scoring class, so a new instrument means adding its survey data and a strategy, and thresholds, alerts and dashboards pick it up.

## Installation

1. Copy the folder into your Odoo `addons` path (depends on `base`, `mail` and `survey`).
2. Install the Python dependencies used by the dashboards and PDF reports: `pip install pandas weasyprint`.
3. Update the apps list and install **AulaMetrics**. With demo data enabled you get a sample school with synthetic users (`orientador@test.com` / `orientador123`, `direccion@test.com` / `direccion123`, tutors with `tutor123`).

All demo data is synthetic and generated by `scripts/generate_demo_data.py`. No real student data is included.
